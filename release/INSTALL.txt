Dungeon Defenders Archipelago 0.8.1

Requires Steam Dungeon Defenders and Archipelago 0.6.8.
Own the DLC for enabled heroes and difficulties.
Tavern themes require all four Lost Eternia Shards DLCs.
Local play only.

INSTALL
1. Install dungeon_defenders.apworld.
2. Extract TotalConversions-v0.8.1.zip into your Dungeon Defenders folder.
   Merge TotalConversions/DD1ArchipelagoCurrent and replace packaged files.
   Keep existing saves and generated settings.
3. Put Dungeon Defenders.yaml in Archipelago/Players, edit it, and generate.
4. Open Dungeon Defenders Client in Archipelago and connect.
5. Choose Play Local in DD1.

Update both the APWorld and TotalConversion when upgrading from 0.8.0.
New reward options require a new seed.

SOURCE
The source ZIP uses the existing GitHub folder layout.
Replace the corresponding source folders with the new ones.
It is not a playable installation.

STARTUP PROBLEMS
Follow any missing-file or configuration warning in the client.
Do not delete the conversion folder: it contains saves.
Logs are in TotalConversions/DD1ArchipelagoCurrent/Config:
DD1ArchipelagoLive.log and, when created, DD1ArchipelagoGame-*.log.
