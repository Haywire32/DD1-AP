# Source code

Dungeon Defenders Archipelago 0.8.1. Local play only.

- `apworld/`: generation, options and client.
- `bridge/`: game communication and reward handling.
- `game/Classes/`: UnrealScript gameplay changes.
- `release/`: YAML and player configuration.
- `tools/`: package builders.

See [Python build](docs/PYTHON-BUILD.md), [game build](game/PATCHING.md),
and [client behavior](docs/SECURITY.md).

Game dependencies require DD1 and a compatible DDDK. They are not included
in this source ZIP. No project-wide reuse license has been selected.
